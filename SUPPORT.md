# Getting help

- **Setting up or using the plugin:** ask on the [WordPress.org support forum](https://wordpress.org/support/plugin/hide-admin-bar-based-on-user-roles/).
- **A bug or an idea:** open an [issue](https://github.com/wpankit/hide-admin-bar-free/issues/new/choose).
- **A security issue:** follow the [security policy](SECURITY.md) and report it privately.
